## ROMS 해양 예측 조회 사이트

국립해양조사원 ROMS 수치예측모델 조회 API(공공데이터포털)를 사용해 좌표별 수온·유향·유속 예측을 지도, 그래프, 표로 보여 주는 사이트입니다.
서버링크: https://roms-3lb9.onrender.com/

## ✨ 주요 기능

- **좌표 및 범위 기반 조회**
  - 위도·경도 직접 입력, 주요 해역 프리셋 버튼(서해, 울릉도, 제주 남쪽, 백령도), 또는 **지도 클릭**을 통한 직관적 좌표 지정
  - 중심 좌표 기준 조회 반경(`±0.05°` ~ `±0.50°`) 설정 지원
- **인터랙티브 예측 지도 (Leaflet)**
  - **수온·유향·유속 동시 시각화:** 수온(파랑→빨강 색상 스펙트럼)과 유향(정북 기준 시계방향 회전 화살표)을 격자 마커로 표현
  - **시계열 탐색:** 날짜/시간 드롭다운 및 타임라인 슬라이더를 통한 8일간의 시간별 예측 변화 확인
  - **관측부이 실측 비교:** 주변 해양관측부이의 실시간 관측 데이터(수온, 유속, 염분)를 지도 위 별도 마커로 오버레이
- **상세 분석 및 데이터 내보내기**
  - 입력 위치에서 가장 가까운(또는 사용자가 클릭한) 예측점의 요약 통계, **SVG 시계열 차트**(수온·유속), 시간별 데이터 테이블 제공
  - 조회된 예측점의 전체 시계열 데이터를 **CSV 파일**로 원클릭 다운로드

## 🛠 기술 스택

- **Frontend:** Vanilla JS (ES6+), HTML5, CSS3 (Grid/Flexbox, 다크모드 자동 지원)
- **Map & Visualization:** Leaflet.js (v1.9.4), Custom Inline SVG Charts
- **Data API:** 공공데이터포털 (해양수산부 국립해양조사원 ROMS 수치예측모델 / 해양관측 조회 서비스)
